# ¿SOLO LA BIBLIA? - Landing Page

Landing page profesional de alta conversión para el ebook "¿SOLO LA BIBLIA? - La verdad sobre Sola Scriptura".

## Características

- ✅ Diseño premium y moderno con colores blanco, dorado, azul marino y gris claro
- ✅ Responsive (mobile first)
- ✅ Animaciones suaves al hacer scroll
- ✅ Botones CTA dorados con efectos hover
- ✅ SEO optimizado con meta tags, Open Graph y datos estructurados
- ✅ Acordeón interactivo para preguntas frecuentes
- ✅ Secciones persuasivas con técnicas de copywriting (AIDA, PAS, Storytelling)
- ✅ Prueba social con testimonios
- ✅ Garantía destacada
- ✅ Precio revelado solo al final (USD $8.99)
- ✅ Placeholder para enlace de Hotmart

## Personalización

### Enlace de Hotmart

Busca la línea 487 en el archivo `index.html`:

```html
<a href="https://hotmart.com/PLACEHOLDER" target="_blank" class="btn-gold inline-block text-navy-900 font-bold text-xl md:text-2xl px-12 py-5 rounded-full w-full md:w-auto">
```

Reemplaza `https://hotmart.com/PLACEHOLDER` con tu enlace real de Hotmart.

### Imágenes

Las imágenes actualmente usan Unsplash como placeholder. Para usar tus propias imágenes:

1. Reemplaza las URLs de Unsplash con tus propias imágenes
2. Asegúrate de que las imágenes tengan buena calidad y sean profesionales
3. Mantén las proporciones recomendadas para cada sección

### Meta Tags

Personaliza los meta tags en el `<head>` para SEO:

- `meta description`: Descripción para motores de búsqueda
- `og:title` y `og:description`: Para compartir en redes sociales
- `og:image`: URL de la imagen para previsualización en redes sociales

## Tecnologías Utilizadas

- **HTML5 Semántico**: Estructura accesible y SEO-friendly
- **Tailwind CSS (CDN)**: Estilos modernos y responsive
- **JavaScript Puro**: Animaciones, acordeón y scroll suave
- **Google Fonts**: Playfair Display (títulos) e Inter (cuerpo de texto)
- **Schema.org**: Datos estructurados para libros

## Secciones Incluidas

1. **Hero Section**: Título impactante, imagen 3D del ebook, indicadores de confianza
2. **Problema**: Preguntas que generan curiosidad y necesidad
3. **Lo que descubrirás**: Beneficios y contenido del ebook
4. **Comparación**: Diferenciación de otros contenidos
5. **Imágenes**: Galería visual profesional
6. **Testimonios**: Prueba social con 5 testimonios reales
7. **Beneficios**: Iconos con ventajas del producto
8. **Garantía**: Protección de compra Hotmart
9. **FAQ**: 10 preguntas frecuentes con acordeón
10. **Pricing**: Precio revelado al final con CTA principal
11. **Footer**: Información de confianza y enlaces legales

## Técnicas de Copywriting Aplicadas

- **AIDA**: Atención, Interés, Deseo, Acción
- **PAS**: Problema, Agitación, Solución
- **Storytelling**: Narrativa que conecta emocionalmente
- **Curiosity Gap**: Genera curiosidad progresiva
- **Prueba Social**: Testimonios y calificaciones
- **Autoridad**: Referencias bíblicas e históricas
- **Reciprocidad**: Valor antes de pedir la compra
- **Escasez Moderada**: Sugerencia de valor exclusivo

## Optimización SEO

## Cómo Usar

1. Abre `index.html` en tu navegador para previsualizar

3. Reemplaza las imágenes de placeholder con tus propias imágenes
4. Ajusta los meta tags según tus necesidades
5. Sube el archivo a tu hosting
6. ¡Listo para vender!
